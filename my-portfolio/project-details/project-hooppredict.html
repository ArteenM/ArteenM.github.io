Machine learning and data

HoopPredict

Analytics platform for NBA predictions with ETL pipelines, feature engineering, model training, and a full-stack frontend for presenting outputs.

  • Python
  • Django
  • React
  • Scikit-learn
  • Pandas
  • BeautifulSoup

What I built

  • Built a full-stack analytics platform combining a Django backend, React frontend, and machine learning workflows.
  • Developed ETL pipelines using API data and web scraping for automated data collection and cleaning.
  • Engineered 40+ features including matchup and performance metrics for model training.
  • Trained and evaluated a Random Forest model to generate structured predictive outputs.
  • Designed REST APIs to serve predictions and supporting analytics to the frontend.

What I learned

  • How much of machine learning work is really about data preparation, validation, and feature design.
  • How to move from a notebook-style experiment to something closer to a usable product.
  • How to build a full stack around analytical outputs instead of treating the model as the whole project.

Why it matters

This project reflects my interest in data-heavy systems and turning raw information into something structured, useful, and visible through a real interface.

AI-Assisted Network Intrusion Detection System

A two-service intrusion detection system that flags anomalous network traffic in real time and uses an LLM to triage and summarize what it finds, with the raw-traffic and secret-holding components deliberately kept apart.

  • C#/.NET
  • ASP.NET Core
  • Pcap
  • ONNX Runtime
  • Docker
  • Gemini API

What I built

  • Split the system into two processes on either side of a privilege boundary: a packet-capture agent with raw-socket access, and a separate, unprivileged service that holds the system's only API credential.
  • Built real-time network flow tracking and trained an Isolation Forest anomaly-detection model, exporting it to ONNX Runtime for inference on live traffic in roughly 5ms per flow.
  • Integrated the Gemini API into the triage service to automatically classify flagged-flow severity and generate incident reports from raw traffic statistics.
  • Developed an automated evaluation pipeline to benchmark detection behavior and latency against simulated port-scan and flood attacks (nmap, hping3) in a controlled environment.
  • Containerized both services with Docker, working through the elevated network capabilities live packet capture requires inside a container.

What I learned

  • How to reason about blast radius when designing a system, not just when securing an existing one — the privilege split only matters if you can explain what a compromise of either side actually costs you.
  • Where the real latency budget in an LLM-assisted pipeline goes: model inference is fast, and the LLM call is the part worth optimizing if this ever needed to run at higher volume.
  • How much container networking changes once you actually need raw packet access inside Docker, versus a typical stateless web service.

Why it matters

This is the project that pushed me past "install a monitoring tool" and into actually designing a detection system — the architecture decisions here (privilege separation, where the LLM sits in the pipeline, what gets measured) are the part I'd most want to walk someone through.

Automation

Job Application Tracker Extension

Chrome extension for extracting, storing, and organizing application data to reduce repetitive manual tracking across job platforms.

  • JavaScript
  • Chrome APIs
  • DOM Parsing
  • Chrome Storage

What I built

  • Built a browser extension to automate job application tracking across multiple platforms.
  • Implemented DOM parsing to extract structured job information from web pages.
  • Used Chrome Storage APIs to persist and organize application data efficiently.
  • Built message-passing logic between content scripts and background scripts.
  • Improved workflow efficiency by reducing repetitive manual entry.

What I learned

  • How automation projects can be useful even when they are relatively small.
  • How to build practical browser tooling around messy real-world page structures.
  • How much value can come from improving a workflow you actually use yourself.

Why it matters

This project is smaller than some of the others, but it is a good example of building a focused tool around a real frustration and making a process noticeably smoother.

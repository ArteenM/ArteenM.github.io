Active Directory Homelab

Enterprise-style lab environment using Active Directory and Wazuh for logging, monitoring, user management, and security investigation practice.

  • Wazuh
  • Active Directory
  • Linux
  • Bash
  • VirtualBox

What I built

  • Configured an Active Directory environment with user accounts, permissions, and group policy management.
  • Integrated Wazuh to monitor system activity and improve visibility into authentication and endpoint behavior.
  • Simulated attacks such as brute force and privilege escalation to study detections and response opportunities.
  • Automated administrative tasks with Bash scripts and documented support and troubleshooting workflows.
  • Investigated authentication and connectivity issues through systematic debugging.

What I learned

  • How identity, logging, and endpoint visibility connect in practical security work.
  • Why clear documentation matters when maintaining multi-system environments.
  • How hands-on labs build a much better understanding of security operations than theory alone.

Why it matters

This project gave me a practical way to learn security monitoring and systems administration while still working within an environment I could iterate on safely.

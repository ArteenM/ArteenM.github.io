P2P File-Sharing Application

Secure peer-to-peer file transfer application built around authentication, encrypted communication, testing, and performance tuning.

  • React
  • TypeScript
  • Node.js
  • Express
  • WebRTC
  • SQL

What I built

  • Built a full-stack application for secure peer-to-peer file transfers using WebRTC.
  • Implemented AES-256-GCM encryption, JWT authentication, and bcrypt hashing for secure transfer and session handling.
  • Built backend services for signaling, network communication, and file transfer coordination.
  • Developed a Jest test suite with 90%+ coverage across unit, integration, and end-to-end testing.
  • Optimized throughput and latency for large file transfers up to 1 GB.

What I learned

  • How to think about security, reliability, and performance together rather than as separate concerns.
  • How much testing helps once a project grows beyond a simple prototype.
  • How to structure a full-stack system so the backend, frontend, and transport layer remain understandable.

Why it matters

This is my strongest all-around software project because it combines product thinking, backend development, security, testing, and measurable performance work.

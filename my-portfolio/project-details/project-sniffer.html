Network Packet Sniffer

C-based packet analysis tool for inspecting low-level traffic, parsing headers, and studying communication patterns across common protocols.

  • C
  • Linux
  • TCP/IP
  • HTTP
  • DNS

What I built

  • Developed a packet analysis tool in C to inspect TCP/IP, HTTP, and DNS traffic.
  • Parsed raw packet headers and payloads for structured analysis and debugging.
  • Investigated communication patterns to identify anomalies and protocol inconsistencies.
  • Logged captured traffic for repeatable troubleshooting and validation.
  • Used the project to deepen my understanding of system-level networking behavior.

What I learned

  • How useful it is to see network behavior at a lower level instead of relying only on higher-level abstractions.
  • How C projects force you to be more explicit about memory, structures, and data layout.
  • How protocol debugging becomes clearer once you have your own tooling around it.

Why it matters

This project is a good example of the kind of systems work I enjoy: close to the machine, detail-heavy, and useful for understanding how things actually behave.

About

A little more context on what I build and how I work.

My recent projects include a privilege-separated network intrusion detection system that uses an LLM to triage flagged traffic, a secure peer-to-peer file-sharing system, an NBA analytics platform with machine learning pipelines, an Active Directory homelab with security monitoring, a C-based packet sniffer, and an STM32 firmware project for SPI-based IMU data acquisition.

Outside of school, I work as an Aquatic Leader with the City of Coquitlam. That role has strengthened my communication, vigilance, and ability to stay composed in fast-moving situations. Those habits carry over directly into how I debug, document, and collaborate on technical work.
